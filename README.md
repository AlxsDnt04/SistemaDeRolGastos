# Sistema de Rol de Gastos

¡Bienvenido/a al **Sistema de Rol de Gastos**! Este proyecto tiene como objetivo facilitar la gestión de gastos y roles financieros dentro de un grupo u organización.

## Descripción

El **Sistema de Rol de Gastos** es una aplicación diseñada para:
- Supervisar y gestionar los gastos compartidos.
- Asignar roles y responsabilidades financieras a los miembros de un grupo.
- Generar reportes y estadísticas para un mejor análisis de los gastos.

Este proyecto está desarrollado utilizando las siguientes tecnologías:
- **HTML:** Estructura del sitio web.
- **CSS:** Diseño y estilos.
- **JavaScript:** Interactividad del cliente.
- **PHP:** Lógica del servidor.

## Características

- Registro y seguimiento de gastos.
- Asignación de roles financieros.
- Visualización de reportes detallados.
- Interfaz amigable y responsiva.
- Autenticación de usuarios para mayor seguridad.

## Requisitos Previos

Antes de instalar el proyecto, asegúrate de tener los siguientes requisitos previos:

- **Servidor web** (por ejemplo, Apache o Nginx).
- **PHP** (versión 7.4 o superior).
- **Base de datos** MySQL o MariaDB.
- **Navegador web** actualizado.
